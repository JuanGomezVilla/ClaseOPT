## 1. Primeros pasos

1. Imprimir por pantalla
    ```py
    print("Hola")
    print('Hola')
    print("Hola 'Juan'")
    print('Hola "Juan"')
    ```
2. En `print()`, se puede especificar como finaliza la línea con `end`, por lo que en este caso, aparecerá directamente *Juan GV*, aunque existan dos *prints*:
    ```py
    print("Juan", end=" ")
    print("GV")
    ```
3. Comentarios: líneas en el código que no son ejecutables. Para una sola línea utiliza `#` y si fuera multilínea, escribe el comentario entre tres comillas simples `'''`
    ```py
    print("Hola")

    # Comentario 1
    '''
    Comentario 2
    Comentario 3
    '''
    print("Buenos días")
    ```
4. Definición de variables:
    ```py
    nombre = "Juan"
    edad = 999
    PI = 3.14
    is_conductor = True # False
    ```
5. Mostrar el contenido de las variables:
    ```py
    nombre = "Juan"
    edad = 999
    print(nombre + " " + str(edad))
    print(f"{nombre} tiene {edad} años")
    ```
6. Pedir al usuario que escriba un valor por consola:
    ```py
    nombre = input("Nombre: ")
    print("Hola, "+ nombre)
    ```
7. Operaciones matemáticas:
    ```py
    numero1 = int(input("Número 1: "))
    numero2 = int(input("Número 2: "))

    print(numero1 + numero2) # Suma
    print(numero1 - numero2) # Resta
    print(numero1 * numero2) # Multiplicación
    print(numero1 / numero2) # División
    print(numero1 // numero2) # División entera
    print(numero1 % numero2) # Resto
    print(numero1 ** numero2) # Elevado
    print(numero1 ** 0) # Elevado a 0 = 1
    print(numero1 ** 0.5) # Raíz cuadrada
    ```
9. Raíz cuadrada de un número (método alternativo a `numero ** 0.5`):
    ```py
    import math

    print(math.sqrt(49))
    ```
10. Convertir un número hexadecimal (en este ejemplo *FF* corresponde a 255):
    ```py
    print(int("FF", 16))
    ```
11. Ejercicio:
    ```py
    coche = "Ferrari"
    ruedas = 3
    is_diesel = True

    print(f"Es un {coche} con {ruedas} ruedas y es diésel? {is_diesel}")
    ```
