## 1. Variantes
- **`if` simple:**
    ```py
    user_password = input("Contraseña: ")

    if user_password == "hola":
        print("Bienvenido")
    ```
- **Combinación de `if-else`:**
    ```py
    user_password = input("Contraseña: ")

    if user_password == "hola":
        print("Bienvenido")
    else:
        print("Credenciales incorrectas")
    ```
- **Combinación de `if-elif-else`:**
    ```py
    edad = int(input("Edad: "))

    if edad < 18:
        print("Es menor de edad")
    elif edad > 65:
        print("Es jubilado")
    else:
        print("Es mayor de edad")
    ```

## 2. Comparadores
- `valor1 == valor2`: igualación, comprueba si dos valores son iguales
- `numero1 > numero2`: comprueba si el *numero1* es mayor que el *numero2*
- `numero1 < numero2`: comprueba si el *numero1* es menor que el *numero2*
- `numero1 >= numero2`: comprueba que el *numero1* es mayor o igual que el *numero2*
- `numero1 <= numero2`: comprueba que el *numero1* es menor o igual que el *numero2*

## 3. Ejercicios resueltos
- El programa pide un número al usuario y dice si es negativo o positivo:
    ```py
    # El usuario escribe un número
    numero = int(input("Número: "))
    
    # Comprobación
    if numero < 0:
        print("Negativo")
    else:
        print("Positivo")
    ```
- El programa pide un número al usuario y comprueba si es par o impar:
    ```py
    numero = int(input("Número: "))
    
    if numero%2 == 0:
        print("Par")
    else:
        print("Impar")
    ```
    > También puede representarse como *numero%2* a secas, ya que esto devuelve 1 ó 0, lo mismo que si fuera *True/False*, respectivamente
- El programa pide al usuario un tipo de combustible (*diesel/gasolina*), y muestra *carbonilla* si el usuario elige *diesel*, muestra *limpio* en caso contrario. **IMPORTANTE:** no cualquier otro caso:
    ```py
    combustible = input("Combustible: ")
    
    if combustible == "diesel":
        print("Carbonilla")
    elif combustible == "gasolina":
        print("Gasolina")
    else:
        print("Combustible no reconocido")
    ```
- Define una variable `is_encendido` que puede ser verdadero o falso, y el programa compara ese resultado, mostrando un mensaje por pantalla si hay luz o no:
    ```py
    is_encendido = True

    if is_encendido:
        print("Hay luz")
    else:
        print("Está oscuro")
    ```
- Modifica el ejercicio anterior para que sea el usuario quien indica si está encendido o apagado:
    ```py
    is_encendido = int(input("Oscuro o apagado [1|0]: "))

    if is_encendido:
        print("Hay luz")
    else:
        print("Está oscuro")
    ```
