

Estructura mental:
```
Por siempre
    Pregunto por una contraseña

    Si son iguales
        Rompo el bucle
    En caso contrario
        Le digo que las contraseñas son iguales
```



## Ejercicio de batería
```py
bateria = 85

while bateria < 100:
    bateria = bateria + 1
    print(bateria)

print("Fin del programa")
```


## Sistema de contraseñas
```py
# Por siempre
while True:
    # Pregunto al usuario por una contraseña
    user_password = input("CONTRASEÑA: ")

    # Si la contraseña es igual a "hola", rompo el bucle
    if user_password == "hola":
        # Rompo el bucle
        break
    
    # En caso contrario, la contraseña es incorrecta
    else:
        # Notifico al usuario
        print("Datos incorrectos")
```


1. Modificar el ejercicio para que la contraseña esté guardada en una variable:
```py
password = "hola"

while True:
    user_password = input("CONTRASEÑA: ")

    if user_password == password:
        break
    
    else:
        print("Datos incorrectos")
```

## Ejercicio de nota
Realiza un ejercicio donde la nota empieza a 0 y va incrementando hasta alcanzar el 10.

- **Solución 1:**
    ```py
    nota = 0

    while nota < 10:
        nota = nota + 1
        print(nota)
    ```
- **Solución 2:**
    ```py
    nota = 0

    while True:
        nota = nota + 1

        if nota >= 10:
            break

    print(nota)
    ```
